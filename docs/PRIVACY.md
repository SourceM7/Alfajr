# Privacy statement

Alfajr Alarm is designed to work completely offline.

- It does not request the internet, location, or storage permissions.
- It has no accounts, analytics, advertising, identifiers, or crash-reporting SDKs.
- It stores selected alarm preferences locally. Android backup may restore non-sensitive preferences.
- Device-local alarm state is excluded from backup, so a restored installation starts with its alarm disabled and must recheck capabilities before activation.

The app does not transmit user data because it contains no network functionality.
